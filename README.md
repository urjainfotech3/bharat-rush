# Bharat Rush: City Tracks — website

Static site for https://urjainfotech3.github.io/bharat-rush/

- `index.html` – game page (trailer, locations, features, screenshots)
- `privacy.html` – privacy policy (use this URL in Play Console)
- `support.html` – help, FAQ and data deletion
- `credits.html` – model, software and sound credits
- `trailer.mp4`, `img/` – trailer and screenshots cut from real gameplay

Publish: push to the `main` branch, then Settings › Pages › Deploy from branch › main / root.
